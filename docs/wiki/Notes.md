The **Notes** tab is a Markdown scratchpad for the visit: headings, lists that continue when you press Enter, task boxes you tick in the preview, quotes, code and **bold**/*italic*. Everything is in one row: **Outline**; **Edit / Split / Preview** (it opens in Edit); **B**, *I*, **H ▾**, bullet, task box and code; **Insert ▾** with **Time** (date and time with the time zone and where the clock syncs from: `w32tm` on Windows, chrony or timesyncd on Linux), **Host info** (this computer's name and AD domain, LAN, MAC, gateway and WAN), **Photo or file…**, link, table, numbered list, quote, strikethrough and rule; the emoji menu; **Redact**; and on the right what's saved, how much is redacted (click it to highlight them) and **File ▾**. **Outline** opens a panel on the left (open from 1440 points wide) with the headings to jump to, open and done tasks, what's redacted with **By hand**, and the word count. The font and size are in **Settings › Notes**; the preview uses the app's own font at that size. Fonts are egui's Sans and Mono plus the log-friendly monospace fonts the computer already has (Consolas, Cascadia Mono, Lucida Console, Courier New on Windows; JetBrains Mono, DejaVu Sans Mono, Liberation Mono, Noto Sans Mono, Fira Mono, Source Code Pro, Ubuntu Mono where installed); sizes run 8 to 32. **File ▾** is for what goes out: **Save** (with autosave off), **Save as** Markdown, plain text or a web page, **Copy**, **Raw copy**, **Open…**, **Autosave** and **Clear**. **Open…** reads a text or config file (up to 5 MB; UTF-8 or UTF-16) in a tab beside Notes: read-only, line numbers, no wrapping, select and copy. It's never saved, redacted or bundled. **Right-click** in the editor for Cut, Copy, Paste and Select all, **Redact** / **Unredact**, and the formatting (Bold, Italic, Inline code, Heading, Bullet list, Task box); a right-click keeps the selection it lands on. In the file viewer it offers Copy and Select all. **Save .md…** suggests a dated name (`notes-2026-11-02.md`). In **Split**, drag the divider to give either side more room (20–80%; double-click for half and half). Font, size and split are remembered. Emoji are drawn a size up, in the style picked at the top of the emoji menu (it stays open while you pick), in any theme: **Match theme** (monochrome; neon in Miami and RGB), **Monochrome**, **Colour** (each emoji in its own colour: faces yellow, ✅ green, ❌ red; egui draws one colour per glyph, so not full-colour art) or **Miami neon**. Hovering an emoji in the menu shows what it's for and its Markdown shortcode (`:white_check_mark:`, `:fire:`…); Preview draws those codes as the emoji. [`assets/notes-format-test.md`](https://github.com/hammerknife404/is-alive/blob/main/assets/notes-format-test.md) uses every element and a spread of emoji, each line saying how it should look: paste it into Notes and switch to Split to check a build offline. [`assets/notes-debug/`](https://github.com/hammerknife404/is-alive/blob/main/assets/notes-debug/) goes further, for debugging: `notes-debug.md` is a checklist to paste into Notes that walks through every feature (views, fonts, formatting buttons, lists that continue, task boxes, emoji and shortcodes, Time and Host info, redaction by hand and from a config, what Copy / Raw copy / Save / Bundle / Clear send out, odd text), and the `viewer-*` files exercise **Open…**: CRLF and tabs with a long line, a UTF-8 BOM, UTF-16 LE and BE, and a binary file it should refuse.

Notes aren't scanned for secrets: what's redacted is what you mark, so nothing ordinary gets mangled. **Redact** (Ctrl+R) redacts the selected text, there and wherever else it appears; with the cursor on a redacted value the button turns into **Unredact**. The **secrets of a loaded backup or export** (every password, PSK, RADIUS secret and key the UniFi or SonicWall converter strips) are held in memory, never saved, and redacted wherever they appear, as whole words, so the staff Wi-Fi password can't slip into a note. Each becomes a `[🔑 REDACTED: …]` marker. **By hand (n)** in the outline lists hand picks and kept values with × to undo; hand picks live only in memory, so after a restart the notes hold their markers. Autosave (every couple of seconds, beside the settings), **Copy**, **Save** and the Site Bundle's **Tech notes** get the redacted text; **Raw copy** (two clicks) copies it as written. The Site Bundle's **Known problems** field works the same way, with its own **Redact** button.
