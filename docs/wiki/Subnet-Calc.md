Subnet calculator for IPv4 and IPv6: enter `10.0.0.0/22`, an address with a netmask (`10.0.0.5 255.255.252.0`) or an ACL wildcard (`0.0.3.255`) for network, broadcast, host range, counts, mask in binary, type (private, CGNAT, link-local…) and the neighbouring blocks; check whether an address is inside; split it into smaller blocks; or enter a range (`10.0.0.5-10.0.1.20`) for the fewest CIDR blocks that cover it. **Sweep** sends it to Subnet Sweep. Works offline.

The results line up in one column: the block's details (click any value to copy it), **Check address** (is an address inside, and which number it is), and **Split into** with the list of smaller blocks (**Copy list** copies one per line). The status row's **Sweep** sends an IPv4 block or range of up to 65,536 addresses to [[Subnet Sweep|Subnet-Sweep]]; **Copy** and **Save…** take the details.
